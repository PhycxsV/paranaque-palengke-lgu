# Paranaque Palengke — LGU

LGU admin portal for branches, commodities, vendors, orders, and monitoring.

## Setup

```bash
npm install
cp .env.local.example .env.local   # or reuse VITE_API_URL=http://localhost:1337/api
npm run dev
```

Runs on [http://localhost:5175](http://localhost:5175).

Uses the same Strapi backend as the customerfront and vendor apps.
